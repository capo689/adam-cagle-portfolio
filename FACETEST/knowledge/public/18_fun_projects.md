# ACE

ACE is the live AI guide built into Adam Cagle's portfolio. Visitors can use push-to-talk or typed chat. Speech is transcribed with Groq Whisper large v3 turbo. A reviewed portfolio RAG retrieves public evidence, and fixed answers plus server-side guardrails control claims and boundaries. Dynamic responses currently use DeepSeek V4 Flash through OpenRouter with a Groq fallback. Fish Audio S2.1 Pro streams the voice through OpenRouter.

ACE's face is a custom Three.js and WebGL particle system. Audio analysis drives the mouth while sentence-level performance cues coordinate intonation with eyes, brows, cheeks, and larger facial expressions. ACE receives the current page, open item, latest presentation, and recent conversation turns as short-term context. This context lives only in the active browser session. The site does not store conversation or browsing history.

# Donkey on the Edge

Donkey on the Edge is a public research and technical-communication project tracing a first-principles path from introductory physics toward quantum gravity. Adam structured a thirty-eight-document curriculum and three-paper evolution, using AI-assisted author, editor, and adversarial-review loops to challenge the writing. The project documents uncertainty and does not claim academic peer review or settled scientific results. Public site: https://donkey-mauve.vercel.app/

# SULU Invaders

SULU Invaders is a playable neon browser arcade shooter built by Adam inside a custom retro-futurist console. It uses JavaScript and Canvas with keyboard, pointer, and touch controls, ship upgrades, shields, multiple enemy types, sound effects, and selectable soundtracks. Public game: https://adamcagle.com/space/

# Ship Happens

Ship Happens is a comedy novel written by Adam Cagle and subtitled A Chad Cruz Zombie Adventure. The public sample follows a funeral-home salesman, a disputed inheritance, and an act of financial jujitsu. It demonstrates comic voice, character introduction, dialogue, scene pacing, and tonal control. Public sample: https://adamcagle.com/writing-samples/ship-happens.html
