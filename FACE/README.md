# FACE

An unlinked, non-indexed WebGL experiment: a procedural gold particle portrait on black.

- No source portrait is loaded or rendered.
- The face, hair, glasses, eyes, mouth, neck, collar, tie, and shoulders are generated from code.
- The loop assembles the portrait, tilts the head, silently mouths “hello world,” straightens, blinks, and stares.
- `prefers-reduced-motion` holds the portrait in its final pose.

Serve the repository root and open `/FACE/`.
